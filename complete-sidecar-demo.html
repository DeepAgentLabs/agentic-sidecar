What is Agentic Sidecar?

Simple Concept: A "sidecar" that watches your AI agent and answers one question before EVERY action: "Should this agent do this right now?"

Agentic Sidecar is a real-time decision supervision layer that sits between your AI agent and your business logic. It evaluates every decision using multiple layers of protection: 

┌──────────────────────────────────────────────────────────┐
│                  YOUR AI AGENT                           │
│         (Makes decisions, wants to execute)              │
└─────────────────────────┬────────────────────────────────┘
                          │ (Every decision goes here)
                          ▼
┌──────────────────────────────────────────────────────────┐
│           AGENTIC SIDECAR (Decision Gate)                │
│                                                          │
│  Phase 1: Rule-Based Checks (Fast & Cheap)             │
│  ├─ Policy Advisor: Is this tool allowed?              │
│  └─ Risk Evaluator: Is this action risky?              │
│                                                          │
│  Phase 2: Intent Validation                            │
│  ├─ Intent Guardian: Does this match user's request?   │
│  └─ Constraint Checker: Within limits?                 │
│                                                          │
│  Phase 3: Budget & Escalation                          │
│  ├─ Budget Guardian: Within cost/token limits?         │
│  └─ Escalation: Need human approval?                   │
│                                                          │
│  Phase 4: AI Evaluation (Optional)                     │
│  ├─ Planner: Is the plan logical?                      │
│  ├─ Critic: Are there risks?                           │
│  └─ Judge: Independent AI verification                 │
│                                                          │
│  Result: ALLOW, WARN, BLOCK, CHALLENGE, REPLAN, etc   │
└──────────────┬───────────────────────────────────────────┘
               │ (Decision with audit trail)
               ▼
┌──────────────────────────────────────────────────────────┐
│          BUSINESS LOGIC (Executes only if ALLOW)        │
│                                                          │
│  ✅ Process payment  ✅ Issue refund  ✅ Send email     │
│  ❌ Block dangerous  ❌ Pause risky   ❌ Escalate high  │
└──────────────────────────────────────────────────────────┘

How to Integrate (Step-by-Step)

1
Install Package
Install Agentic Sidecar from PyPI
pip install agentic-sidecar==0.6.0
2
Create Sidecar Instance
Initialize with your configuration
from agentic_sidecar import Sidecar sidecar = Sidecar( on_sidecar_failure="fail_closed", risk_block_threshold="HIGH" )
3
Add Components (Optional)
Enable Planner, Critic, Judge as needed
from agentic_sidecar import ( PlanEvaluator, CriticEvaluator, JudgeEvaluator, OpenAIJudge ) sidecar = Sidecar( on_sidecar_failure="fail_closed", planner=PlanEvaluator(enabled=True), critic=CriticEvaluator(enabled=True), judge=JudgeEvaluator( provider=OpenAIJudge(model="gpt-4") ) )
4
Wrap Your Agent
Connect Sidecar to your agent framework (LangGraph, AutoGen, CrewAI)
from agentic_sidecar.adapters.langgraph import attach # Your existing agent agent = create_react_agent(model, tools) # Add protection (1 line) agent = attach(agent, sidecar)
5
Evaluate Decisions
Every decision goes through Sidecar first
from agentic_sidecar import DecisionContext decision = sidecar.evaluate( DecisionContext( tool_name="issue_refund", tool_args={"amount": 500} ) ) if decision.status == "ALLOW": execute_action() elif decision.status == "BLOCK": handle_blocked(decision.reason)
6
Monitor & Iterate
Use CLI for live monitoring and audit trails
# Live execution tracking agentic-sidecar status --follow # View audit trail agentic-sidecar audit --export pdf
