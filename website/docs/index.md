# Agentic Sidecar

Should this proposed action proceed under the declared policy and intent?

## What it does

Decision records and adapter-mediated allow, block, or escalation behavior.

## What you need

Proposed tool actions, policy rules, intent constraints, and recorded budgets.

## Start here

Compute a deny verdict, then demonstrate governed execution.

[Follow the quickstart](developer-guide.md#quickstart).

## Scope

evaluate() produces a verdict. Actual enforcement requires the caller or a governed adapter; Observe mode does not block execution.

[Read the detailed developer guide](developer-guide.md).
